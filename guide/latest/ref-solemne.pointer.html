solemne.pointer

solemne.pointer A pointer to a source: a document's code, alone or with a citation after an underscore (C.NIC-0325_3); a Bible reference by book, chapter and verse (MAT_18_19, PHP_3_17-20); a Gryson siglum and the place cited (IS_ety_1.2.3); each may start with cf_ for a loose reference; or an SCTA resource. A code's prefix is a category's (COLL for both kinds of collection), or W; it holds letters, digits, dots and hyphens; an underscore only separates a code from its citation.
