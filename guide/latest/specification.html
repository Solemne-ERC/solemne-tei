The SOLEMNE Encoding Guidelines

The specification

The schema takes the modules of TEI below, and from each only the elements listed: an element outside them fails the RelaxNG. Each part's specifications follow, in the parts' order. An element the specifications change carries its tier there; the others take theirs from this table.
