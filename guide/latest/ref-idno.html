<idno>

<idno> (identifier) supplies any form of identifier used to identify some object, such as a bibliographic item, a person, a title, an organization, etc. in a standardized way. [14.3.1. Basic Principles 2.2.4. Publication, Distribution, Licensing, etc. 2.2.5. The Series Statement 3.12.2.4. Imprint, Size of a Document, and Reprint Information]

Note

idno should be used for labels which identify an object or concept in a formal cataloguing system such as a database or an RDF store, or in a distributed system such as the World Wide Web. Some suggested values for type on idno are ISBN, ISSN, DOI, and URI.

Example
<idno type="ISBN">978-1-906964-22-1</idno>
<idno type="ISSN">0143-3385</idno>
<idno type="DOI">10.1000/123</idno>
<idno type="URI">http://www.worldcat.org/oclc/185922478</idno>
<idno type="URI">http://authority.nzetc.org/463/</idno>
<idno type="LT">Thomason Tract E.537(17)</idno>
<idno type="Wing">C695</idno>
<idno type="oldCat">
 <g ref="#sym"/>345
</idno>

In the last case, the identifier includes a non-Unicode character which is defined elsewhere by means of a <glyph> or <char> element referenced here as #sym.

SchematronThe formal title holds the document's code (an identifier without a type), its category and its type, once each; an export adds the permalinks of the levels the file belongs to.

<sch:rule context="tei:fileDesc/tei:titleStmt/tei:title[@type = 'formal']">
<sch:assert id="formal-title-idnos"
 test="count(tei:idno[not(@type)]) = 1 and count(tei:idno[@type = 'category']) = 1 and count(tei:idno[@type = 'type']) = 1 and (every $level in ('work', 'version', 'witness', 'transcription') satisfies count(tei:idno[@type = $level]) le 1)">The formal title holds
the document's code (an identifier without a type), its category and its type, once each, and at
most one permalink for each level the file belongs to.</sch:assert>
</sch:rule>

SchematronAn identifier in the title statement is the code, the category, the type, or a level's permalink.

<sch:rule context="tei:fileDesc/tei:titleStmt/tei:title/tei:idno">
<sch:assert id="idno-type"
 test="not(@type) or @type = ('category', 'type', 'work', 'version', 'witness', 'transcription')">An identifier in the formal title is the code (without a type), the

</sch:rule>
SchematronThe document's code is a prefix of capitals, a dot, the title part, its subparts joined by hyphens, and any source part after a dot, beginning with a letter: a date is joined by a hyphen.

<sch:rule context="tei:fileDesc/tei:titleStmt/tei:title[@type = 'formal']/tei:idno[not(@type)]">
<sch:assert id="code-format"
 test="matches(normalize-space(.), '^[A-Z]+\.[A-Za-z0-9]+(-[A-Za-z0-9]+)*(\.[A-Za-z][A-Za-z0-9]*(-[A-Za-z0-9]+)*)*$')">The document's
code (<sch:value-of select="normalize-space(.)"/>) begins with its category's prefix and a dot, holds
only letters, digits, dots and hyphens, and joins its title's parts, the date among them, by
hyphens; a part after another dot is a source part, beginning with a letter.</sch:assert>
</sch:rule>
SchematronThe document's code begins with its category's prefix: COLL for both kinds of collection, the category itself for the others; UNK's any.

<sch:rule context="tei:fileDesc/tei:titleStmt/tei:title[@type = 'formal']/tei:idno[not(@type)]">
<sch:let name="category"
 value="normalize-space(../tei:idno[@type = 'category'][1])"/>
<sch:let name="prefix"
 value="substring-before(normalize-space(.), '.')"/>
<sch:assert id="code-category"
 test="$category = ('', 'UNK') or $prefix = (if ($category = ('SYSCOLL', 'CHRCOLL')) then 'COLL' else $category)">The document's code
(<sch:value-of select="normalize-space(.)"/>) begins with its category's prefix (<sch:value-of select="if ($category = ('SYSCOLL', 'CHRCOLL')) then 'COLL' else $category"/>, for the category
<sch:value-of select="$category"/>).</sch:assert>
</sch:rule>
