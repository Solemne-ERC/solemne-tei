<altIdentifier>

<altIdentifier> (alternative identifier) contains an alternative or former structured identifier used for a manuscript or other object, such as a former catalogue number. [11.4. The Manuscript Identifier]

Derived fromatt.typed
Status Required
Datatype teidata.enumerated
Legal values are:
former
a former shelfmark
siglum
an editor's siglum for the manuscript
code
the project's short code for the manuscript, as in a file's code (Mun-BSB-4592)
Contained by
msdescription: msIdentifier
May contain
core: note
header: idno
msdescription: collection institution repository
namesdates: bloc country district geogName placeName region settlement
Note

An identifying number of some kind must be supplied if known; if it is not known, this should be stated.

Example
<altIdentifier>
 <settlement>San Marino</settlement>
 <repository>Huntington Library</repository>
 <idno>MS.El.26.C.9</idno>
</altIdentifier>
