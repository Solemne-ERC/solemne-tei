Appendix B The rules

Every rule of the schema: the RelaxNG's restrictions, which the import refuses a file for breaking, and the Schematron's rules, whose errors and warnings it reports. Each has its tier and the part that explains it, where a counter-example shows it broken. Generated from the specifications.

source-pointer-formRelaxNGerrorfullWhat is marked in the textA pointer to a source: a document's code, alone or with a citation after an underscore (C.NIC-0325_3); a Bible reference by book, chapter and verse (MAT_18_19, PHP_3_17-20); a Gryson siglum and the place cited (IS_ety_1.2.3); each may start with cf_ for a loose reference; or an SCTA resource. A code's prefix is a category's (COLL for the three kinds of collection, BIB for the Bible's file, W for a work known by its siglum); it holds letters, digits, dots and hyphens; an underscore only separates a code from its citation.
text-note-typeSchematronerrorfullWhat is marked in the textIn the text, a note's type is its layer.

source-note-codesSchematronwarningfullWhat is marked in the textA source, reception or attribution note's codes are in source, not in its words. A word starting C. or D. is taken for a code only in a code's form, older ones included: a letter after the dot, then a hyphen, an underscore or a dot, and a digit (C.NIC-0325, C.MEA_0845), so that Gratian's D.5, C.16 or D.LXXVI isn't.
